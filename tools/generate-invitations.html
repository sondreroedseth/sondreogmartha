Lag private invitasjonslenker

Åpne denne filen lokalt på datamaskinen. Navn og koder behandles bare i nettleseren; ingen data sendes til en server. Verktøyet lager nye ID-er hver gang. Bruk det kun for nye invitasjoner, og ta vare på resultatet før du lukker siden.

Bruk de faktiske navnene. Skrivemåten beholdes; navn blir ikke tolket eller delt automatisk.

1. Invitasjonsregister

Kopier inn i Invitations, fra første tomme rad under overskriften. Kolonnene er Invitation ID, Code hash, Active.

2. Gjester

Kopier inn i Guests, fra første tomme rad under overskriften. Alle 13 kolonner må følge med.

3. Private lenker

Lagre disse privat før du lukker siden. Send hver lenke kun til personene på den invitasjonen. Lenken gir tilgang til alle svar og matbehov innen den invitasjonen. Ikke legg resultatene i GitHub eller publiseringsmappen.

For å trekke tilbake en lenke: sett Active til FALSE i Invitations. For å bytte en kode uten å miste svar: behold Invitation ID og Guest ID, og bytt bare kodehashen. Se RSVP_SETUP.md.
